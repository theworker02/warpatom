# warpatom

Warp URLs and atom query parts with stable normalization.

**Site:** https://theworker02.github.io/warpatom/

## Install / run

```bash
git clone https://github.com/theworker02/warpatom.git
cd warpatom
node src/cli.js
node --test
```
